# onlyhuman for VS Code

Support for `*.human` and `*.bot` spec files, the pair written by a human and generated by a robot.

- Syntax highlighting for `$entity`, `?state`, `@service`, `#requirement`, operators and comments
- Linting: undefined references, bad indent, dangling operators, unused definitions, missing sibling file and broken `[path][line]` pointers
- Go to definition: a reference goes to its header, a definition header in `.human` goes to the same header in `.bot`, and a header in `.bot` goes to the code line it points to

Source and the full syntax: https://github.com/Benjit87/onlyhuman
